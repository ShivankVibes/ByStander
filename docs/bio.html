🚀 About ByStander

ByStander is an all-in-one IoT smart desk robot built on an ESP32 microcontroller with dual SSD1306 OLED displays, a 4x4 matrix keypad, cloud MQTT real-time synchronization, voice assistant interaction, and Bluetooth Low Energy driver for Sphero Ollie.

👀 Dual 128x32 OLED Eyes
⌨️ 4x4 Matrix Keypad
🏎️ Sphero Ollie Pilot
🎵 Spotify API Controller
⏱️ Pomodoro Focus Hub
🕒 NTP Real-Time Clock
